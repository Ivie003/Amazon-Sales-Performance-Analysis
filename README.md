# Amazon Sales Performance Analysis

## Project Overview

This project analyses Amazon sales performance using 50,000 sales records covering 2022–2023.

## Business Questions

1. How much revenue did the company generate, and how did sales change over time?
2. Which product categories generated the most revenue?
3. Which products are the top performers by revenue?
4. Which customer regions generated the most revenue?
5. Which months had the highest and lowest sales?

## Tools Used

- Excel
- Google Sheets
- Amazon S3
- AWS QuickSight

## Key Findings

- Total revenue: $32.87M
- Total orders: 50,000
- Units sold: 149,970
- Top category: Beauty
- Top region: Middle East
- Highest revenue month: January 2023
- 2023 revenue growth: 0.54%

## Recommendations

- Strengthen high-performing categories.
- Investigate slow revenue growth.
- Learn from strong regional markets.
- Improve inventory planning.
- Monitor top-performing products.

## Dashboard

AWS QuickSight was used to create the Business Intelligence dashboard.
